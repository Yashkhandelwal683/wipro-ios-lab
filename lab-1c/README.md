
# Lab 1C: Collections and Enums

## Objective
Store and transform related data using Array, Set, Dictionary, and Enum in Swift.

## R1: Array
Maintained an array of course names and performed:
- Add a course
- Remove a course
- Sort courses
- Filter courses
- Search for a course

## R2: Set
Used a Set to remove duplicate student IDs and calculated the count of unique students.

## R3: Dictionary
Created a Dictionary to store student names and marks.
- Found the topper.
- Identified students below a marks threshold.

## R4: Enum
Created a TaskPriority enum with Low, Medium, High, and Urgent cases.
Used switch to display user-friendly labels.

## R5: Choosing Collections

### Array
An Array is useful when data needs to be stored in an ordered collection and elements may be repeated.

### Set
A Set is useful when unique values are required and duplicates should be removed.

### Dictionary
A Dictionary is useful when data needs to be stored as key-value pairs for quick lookup.

### Enum
An Enum is useful when a value must be one of a fixed number of predefined options.

## Conclusion
This lab demonstrates the use of Swift collections and enums
to store, manipulate, filter, and organize data.
