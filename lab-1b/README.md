
# Lab 1B - Access Control and Encapsulation

## R1 - BankAccount
Created a BankAccount class with private balance and public deposit and withdraw methods.

## R2 - Validation
Invalid deposits and withdrawals are rejected.
Withdrawals greater than balance are not allowed.
Negative initial balance is handled.

## R3 - Access Modifiers
Private: Accessible only inside class.
Fileprivate: Accessible only inside the same file.
Internal: Accessible inside the module.
Public: Accessible outside the module.

## R4 - Encapsulation
Balance is private and cannot be modified directly.
It can only be changed through deposit and withdraw methods.
